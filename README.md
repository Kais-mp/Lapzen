## 🌟 About Lapzen

Lapzen is your go-to destination for premium laptops and computing devices in Pakistan. We curate a selection of high-performance laptops, workstations, and business devices from top brands, ensuring you get the best value for your investment. Our AI-powered chatbot helps you find the perfect device tailored to your needs.

### Key Features
- **Curated Catalog**: Handpicked selection of premium laptops and workstations
- **AI-Powered Chatbot**: Get personalized recommendations instantly
- **Secure Payments**: Integrated with Stripe for seamless transactions
- **Real-time Inventory**: Always up-to-date stock information
- **Responsive Design**: Optimized for all devices
- **Admin Dashboard**: Comprehensive management tools for inventory, orders, and users

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Database & Auth**: [Supabase](https://supabase.com/)
- **AI/Chat**: [Groq](https://groq.com/) (Llama 3.3 70B)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/), [Shadcn UI](https://ui.shadcn.com/)
- **Deployment**: Vercel-ready

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm, yarn, pnpm, or bun
- Supabase account

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/lapzen.git
   cd lapzen
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. **Set up environment variables**
   Create a `.env.local` file in the root directory and add your keys:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   GROQ_API_KEY=your_groq_api_key
   META_ACCESS_TOKEN= Your-Meta_Acess_Token
   NEXT_PUBLIC_META_PIXEL_ID=Your_meta_pixel_Id
   ```

4. **Set up the database**
   

5. **Run the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

   Open [http://localhost:3000](http://localhost:3000) to view the application.
